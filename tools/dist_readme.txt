植物战场 (Plant Battlegrounds)

【怎么玩】
解压后双击 plant_battlegrounds.exe，不需要安装任何东西。

【运行要求】
Windows 10 / 11 64 位，显卡支持 OpenGL 3.3（一般机器都行）。

【操作】
  选园丁     点击卡片开始对局
  招募阶段   拖拽卡牌：
               商店 → 手牌    购买
               手牌 → 草坪    上场
               草坪 → 商店    铲除
               草坪内拖动     调整站位
  升级 / 技能  草坪区右上角按钮；左上角圆框点一下放技能
  浇水 / 保鲜  商店区右上角
  空格         出战（进入战斗）
  战斗阶段     空格 跳到结果 ｜ S 切换播放速度
  F1 日志 ｜ R 重开 ｜ ESC 退出

【玩法要点】
  三连（光合融合）  凑齐 3 张同名植物合成金色，并**白拿一张高一级草坪的植物**
  草坪等级          决定商店能刷出的植物等级，也能让三连奖励给到更强的植物
  关键字            荆棘=嘲讽（必须被优先攻击）｜护盾=免疫一次伤害 ｜毒刺=命中即毒杀
